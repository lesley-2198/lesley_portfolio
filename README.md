# Lesley Ngcobo - Data Scientist & ML Specialist Portfolio

A modern, interactive portfolio website showcasing expertise in Data Science, Machine Learning, and problem-solving capabilities. Built with a cyberpunk neural network aesthetic and cutting-edge web technologies.

## 🎨 Design & Theme

- **Dark gradient background** (#0f0f23 → #16213e)
- **Cyberpunk/neural network aesthetic** with animated SVG elements
- **Modern typography** using JetBrains Mono font
- **Teal/cyan color scheme** (#64ffda, #4ecdc4) with accent colors
- **Floating particle animations** in the background

## 🚀 Features

### Interactive Elements
- **Typing animation** for hero title text
- **Animated counters** that start when scrolled into view
- **Hover effects** on project cards and buttons
- **Animated skill bars** filling on scroll using Intersection Observer
- **Floating particle background** animation
- **Neural network SVG** with animated connections and nodes

### Sections
1. **Hero Section** - Animated typing title and neural network background
2. **Stats Dashboard** - Animated counters for projects, models, datasets, and accuracy
3. **Tech Stack Visualization** - Categorized skills with animated progress bars
4. **Data Visualization** - Horizontal animated bar charts showing project impact
5. **Featured Projects** - Grid of project cards with GitHub links
6. **Contact Section** - Social links with hover glow effects

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/lesley-2198/lesley_portfolio.git
   cd lesley_portfolio
   ```

2. **Open in browser**
   - Simply open `index.html` in any modern web browser
   - No build process or dependencies required

3. **Customize content**
   - Update project information in `index.html`
   - Modify skills and percentages
   - Replace placeholder images with actual project screenshots
   - Update contact information and links

## 🎨 Customization

### Colors
The color scheme can be easily modified in `style.css`:
```css
:root {
    --primary-color: #64ffda;
    --secondary-color: #4ecdc4;
    --accent-color: #ff6b6b;
    --bg-dark: #0f0f23;
    --bg-medium: #1a1a2e;
    --bg-light: #16213e;
}
```

### Animations
- **Typing speed**: Modify `typingSpeed` and `deletingSpeed` in `script.js`
- **Particle count**: Adjust `maxParticles` in the ParticleSystem class
- **Animation timing**: Customize CSS animation durations and delays

### Content Updates
- **Skills**: Update percentages and skill names in HTML
- **Projects**: Modify project descriptions, tech tags, and GitHub links
- **Stats**: Change counter values in the stats dashboard
- **Contact**: Update email, LinkedIn, and GitHub URLs

## 🌟 Performance Features
